# 🧠 HemaScope AI – Smart Blood Analyzer Dashboard

HemaScope AI is a web-based healthcare monitoring system that simulates real-time blood analysis using dataset-driven values. It integrates Firebase for patient data storage and applies rule-based AI logic to generate health insights and risk predictions.

---

## 🚀 Features

- 🔐 User Login System (Firebase Authentication)
- 📝 Patient Data Entry Form
- ☁️ Firebase Firestore Integration (Store & Fetch Patient Data)
- 📊 Interactive Dashboard UI
- 🧬 Dataset-based Health Parameter Generation (Hb, Glucose, BMI, etc.)
- 🤖 Rule-Based AI Health Risk Analysis
- 📈 Data Visualization using Chart.js
- 🔄 Simulation Mode (Sensor-ready architecture)

---

## 🏗️ Project Flow

---

## 📊 Data Source

- Real-world medical dataset (Diabetes dataset)
- Converted from CSV → JSON format
- Used to simulate biomedical sensor outputs

---

## 🧠 AI Logic

The system uses rule-based logic for predictions:

- Low haemoglobin → Anaemia risk
- High glucose or BMI → Increased health risk
- Generates health status and recommendations dynamically

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Database:** Firebase Firestore  
- **Authentication:** Firebase Auth  
- **Visualization:** Chart.js  
- **Data Handling:** JSON (from CSV dataset)
